# MP3 Finder (Android)

Android-приложение для поиска MP3-файлов в каталоге Internet Archive и скачивания доступных файлов в папку `Music`.

## Возможности
- поиск по названию или исполнителю;
- просмотр найденных записей;
- потоковое прослушивание;
- скачивание MP3 через системный Download Manager;
- уведомление Android о завершении загрузки.

## Сборка APK
Требуется Android Studio (или Android SDK) и JDK 17.

1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Можно собрать из терминала после установки Gradle и Android SDK:
`gradle assembleDebug`

## Источник и права
Поиск выполняется через публичный API Internet Archive. Наличие файла в каталоге не означает автоматически, что на него нет авторских прав. Скачивайте и используйте только материалы, для которых у вас есть соответствующее разрешение; проверяйте условия конкретной записи.

## Примечание
Это стартовая версия. Для релиза в Google Play потребуется дополнительно проверить правила каталога, обработку ошибок сети, политику конфиденциальности и требования к целевому SDK.
